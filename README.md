# Focus Forge - A Time Management Web App
Focus Forge is a time management web app designed to help users improve their productivity using different time-tracking tools such as a Stopwatch, Countdown Timer, and Pomodoro Timer. It allows users to manage their time effectively through a stylish, user-friendly interface with theme toggle options for light and dark modes.

# Features
- Stopwatch:       Start, stop, and reset the stopwatch to track your time.
- Countdown Timer: Set a custom time for countdown and pause/resume the timer.
- Pomodoro Timer:  Use the Pomodoro technique to work in intervals with short and long breaks.
- Theme Toggle:    Switch between light and dark mode for personalized visual experience.

# Tech Stack
- HTML: Structure of the app.
- CSS: Styling and layout of the app.
- JavaScript: Logic for Stopwatch, Countdown Timer, and Pomodoro Timer functionalities.
- Custom Fonts: For a unique and attractive look.

# Usage
- Stopwatch: Click "Start" to begin the stopwatch. Click "Stop" to stop it and "Reset" to reset the timer back to 00:00:00:00.

- Countdown Timer: Enter hours, minutes, and seconds for your countdown. Click "Set" to set the timer and "Start" to begin. You can pause/resume with the "Pause" button and reset it using the "Reset" button.

- Pomodoro Timer: Choose between a short or long break and click "Start" to begin the Pomodoro timer. Use the "Pause" button to pause and resume the timer.
